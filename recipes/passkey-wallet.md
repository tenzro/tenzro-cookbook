# Passkey wallet (pointer)

On Tenzro Network a person's wallet is a WebAuthn passkey held by the platform authenticator. The passkey's P-256 key never leaves the authenticator, identity is derived from the passkey, and enrollment includes proof of possession, so there is nothing to write down.

This recipe contains no code on purpose: the working walkthrough lives in the live tutorial and we do not copy code here that we have not run ourselves.

Source: [Build a passkey wallet](https://www.tenzro.com/tutorials/build-a-passkey-wallet).
